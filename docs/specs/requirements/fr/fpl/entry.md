# Manager

- **FR-FPL-ENT-001** — The system shall return a manager's team name, overall points, overall rank, and the ids of that manager's classic leagues.
- **FR-FPL-ENT-002** — When no manager is supplied, the system shall use the operator's team.
- **FR-FPL-ENT-003** — The system shall refuse a manager request that supplies no manager when no operator team is configured, and shall return that refusal as a tool error on a completed response.
- **FR-FPL-ENT-004** — The system shall refuse an unknown manager id, and shall return that refusal as a tool error on a completed response.
