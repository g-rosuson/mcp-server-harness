# Squad

- **FR-FPL-SQD-001** — The system shall return the operator's bank, squad value, and free transfers remaining.
- **FR-FPL-SQD-002** — The system shall return each squad player with name, club, position, pitch or bench slot, and purchase price in millions.
- **FR-FPL-SQD-003** — The system shall return which chips are still available and which chips have been used.
- **FR-FPL-SQD-004** — The system shall refuse the squad request when operator credentials are not configured, and shall return that refusal as a tool error on a completed response.
- **FR-FPL-SQD-005** — After the identity provider rotates the operator's refresh token, a later squad request in the same process shall still succeed.
