# Gameweek

- **FR-FPL-GWK-001** — The system shall return the current gameweek and the next gameweek, each with its name, deadline, and whether it has finished.
- **FR-FPL-GWK-002** — When a gameweek number is supplied, the system shall return that gameweek's name, deadline, and whether it has finished.
- **FR-FPL-GWK-003** — The system shall refuse a gameweek number that is not in the current season, and shall return that refusal as a tool error on a completed response.
