# Picks

- **FR-FPL-PCK-001** — The system shall return a manager's starters, bench, captain, vice-captain, active chip, and gameweek points for a gameweek.
- **FR-FPL-PCK-002** — When no manager is supplied, the system shall use the operator's team.
- **FR-FPL-PCK-003** — When no gameweek is supplied, the system shall use the current gameweek.
- **FR-FPL-PCK-004** — The system shall refuse a picks request that supplies no manager when no operator team is configured, and shall return that refusal as a tool error on a completed response.
