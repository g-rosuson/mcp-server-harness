# League

- **FR-FPL-LGE-001** — The system shall return a page of classic-league standings, including rank, previous rank, manager name, team name, gameweek points, and total points.
- **FR-FPL-LGE-002** — When no page is supplied, the system shall return the first page.
- **FR-FPL-LGE-003** — The system shall refuse an unknown league, and shall return that refusal as a tool error on a completed response.
